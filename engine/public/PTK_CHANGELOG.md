# PTK Proxy Tools 1.0.0

- Bộ engine local đầy đủ: providers, OAuth, combos, usage, quota, token saver và MITM.
- Thiết lập tập trung với key riêng Codex / Antigravity / Cursor.
- Scope cx/* và ag/* tự nhận model mới, kiểm tra quyền sau khi resolve alias.
- MITM ghi nhớ key được chọn, chỉ gỡ hosts do PTK tạo.
- DNS Google qua HTTPS là lựa chọn có cấu hình.
- Loại bỏ nút cloud relay, tunnel và cập nhật sang package khác khỏi giao diện local.
